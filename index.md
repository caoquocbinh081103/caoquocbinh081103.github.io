## 🧩 Additional Information

**What is Markdown?**  
Markdown is a simple way to format text using symbols. For example, wrapping code in triple backticks (```) creates a code block. It's the standard format used by GitHub and most AI tools.

**Does this modify my original files?**  
No. The tool only *reads* your code and creates a new Markdown file. Your original files remain untouched.

**Can I use this on Mac or Linux?**  
While this guide focuses on Windows, the tool is built with web technologies, so it should work on any operating system with a modern browser.
